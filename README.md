Movie Stack Pro
Open index.html in a browser.

Included:
- Sidebar navigation
- Home dashboard and stats
- Currently Watching / Watched / Not Watched / All
- Watchlist, favorites, history and genre filters
- Search, sorting and grid/list view
- Add movie modal with poster URL
- Status and favorite persistence via localStorage
- Random movie / detail card
- Dark/light theme
- Responsive mobile layout

Note: poster URLs are remote demo images. For a production site, connect a movie database/API and your own backend/authentication.
